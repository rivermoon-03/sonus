# Bundled visual assets

`wh-1000xm6-black.svg` is an original Sonus vector illustration based on the
appearance of Sony's WH-1000XM6 black headset. It contains only SVG paths,
shapes, gradients, and filters; no Sony raster image is embedded.

The reference product page is <https://www.sony.co.kr/headphones/products/wh-1000xm6>.
