쓰기 잠금 해제 안내

잠금을 해제하면 실기기에서 검증된 설정(DSEE, Speak-to-Chat, 이퀄라이저, Bluetooth 연결 모드 등)을 직접 변경할 수 있습니다. 노이즈 제어·안전 청취처럼 검증되지 않은 항목은 해제 후에도 계속 조회 전용으로 남습니다.

Sonus는 Sony의 공식 소프트웨어가 아닙니다. 변경이 제대로 반영되지 않거나 기기를 재시작해야 적용되는 경우가 있을 수 있습니다. 개발·상태 확인 목적으로만 사용하는 것을 권장합니다.

  • 변경값은 적용 후 다시 읽어 확인합니다.
  • 전원 끄기·초기화·페어링·펌웨어 기능은 실행하지 않습니다.

이 안내는 우측 상단의 "검증된 설정만 쓰기" 배지를 눌러 잠금을 해제할 때마다 표시됩니다. 이 탭에서는 잠금을 해제하지 않고도 언제든 다시 확인할 수 있습니다.

설정 변경 전 확인

Sonus는 실측으로 검증한 설정만 변경하지만 비공식 Linux 드라이버입니다. 설정 변경 중 Bluetooth 연결이 끊기거나 기기 동작이 달라질 수 있습니다.

  • 변경값은 적용 후 다시 읽어 확인합니다.
  • 전원 끄기·초기화·페어링·펌웨어 기능은 실행하지 않습니다.
