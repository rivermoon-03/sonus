# XM6 상태·설정 API와 CLI 설계

## 목표

연결된 Sony WH-1000XM6에서 안전하게 확인한 상태와 설정을 타입이 있는 Python
API로 제공하고, 같은 API를 사용하는 통합 CLI를 만든다. 이후 GUI는 이 API의 또
다른 소비자로 추가한다.

이 단계에서 말하는 "모든 설정"은 Sony 공식 XM6 도움말에 나온 기능 중 직접
통신으로 안전하게 확인할 수 있는 항목 전체를 뜻한다. 응답을 확인하지 못한 항목은
추측해서 구현하지 않고 `미확인` 또는 `미지원`으로 기록한다.

## 선택한 접근

기능 레지스트리와 타입 안전 API를 중심으로 구현한다. 기능 정의에는 다음 정보를
선언한다.

- 사람이 읽을 이름과 안정된 키
- 조회 요청 및 응답 판별 규칙
- 원시 응답을 Python 값으로 바꾸는 코덱
- 읽기/쓰기 지원 여부와 안전 등급
- 값 검증 및 쓰기 요청 생성 규칙

일반 CLI와 향후 GUI는 원시 바이트를 알지 못한다. 읽기 전용 `discover`만 아직
승격되지 않은 조회 후보를 실행하고, 원시 응답과 판독 상태를 보여준다.

## 계층과 책임

```text
CLI/GUI -> device -> messages -> protocol -> transport
```

- `transport`: SDP와 RFCOMM 연결만 담당한다.
- `protocol`: 데이터 묶음, ACK, 재시도, 응답·알림 분리를 담당한다.
- `messages`: 명령 정의, 기능 레지스트리, 값 코덱을 담당한다.
- `device`: 연결 수명, 기능 조회·설정, 상태 스냅샷, 자동 복원을 담당한다.
- `cli`: 입력과 표시만 담당한다.

## 안전 등급

- `READ_ONLY`: 상태 조회. 기본 실행 가능하다.
- `REVERSIBLE`: 현재 값을 먼저 읽고 동일 세션에서 복원할 수 있는 설정. 명시적인
  `set`에서만 변경한다.
- `EXPERIMENTAL_READ`: 의미가 아직 확정되지 않은 읽기 후보. `discover`에서만
  실행한다.
- `BLOCKED`: 전원 끄기, 초기화, 페어링 해제, 펌웨어 갱신, 인증·보호 우회와 관련된
  작업. 코드와 레지스트리에 실행 가능한 명령으로 넣지 않는다.

실기기 쓰기 검증은 원값 읽기, 새 값 쓰기, 새 값 재조회, 원값 쓰기, 원값 재조회를
한 작업으로 실행한다. 어느 단계에서든 실패하면 가능한 범위에서 원값 복원을 다시
시도하고 오류를 보고한다.

## 공개 API

`SonyXm6Device`는 연결된 세션을 감싸고 다음 동작을 제공한다.

- `get(key)`: 기능 하나 조회
- `get_many(keys)` / `snapshot()`: 여러 기능을 독립적으로 조회하고 지원 상태 포함
- `set(key, value)`: 확인된 가역 설정 변경
- `temporary_setting(key, value)`: 검증용 문맥 관리자, 종료 시 원값 복원
- `capabilities()`: 등록 기능과 현재 지원 상태 설명

각 결과는 값뿐 아니라 `supported`, `writable`, `source`, `raw`를 포함한다. 한 기능의
시간 초과가 전체 상태 출력을 실패시키지 않도록 여러 기능 조회는 항목별 오류를
결과에 담는다.

## CLI

- `sonus status`: 배터리, 버전, 연결 및 핵심 음향 상태 요약
- `sonus settings`: 알려진 모든 설정과 지원/쓰기 가능 여부 표시
- `sonus get KEY`: 한 항목의 값과 원시 근거 표시
- `sonus set KEY VALUE`: 가역성이 확인된 설정만 변경
- `sonus discover`: 읽기 전용 후보를 실행해 JSON으로 기록
- 기존 `probe`, `send`, `sniff`: 프로토콜 개발용 저수준 명령으로 유지

MAC 주소와 채널은 공통 인자로 받되, 채널을 생략하면 SDP로 찾는다. 사람이 읽는
표시가 기본이며 `--json`은 자동화에 쓸 안정된 구조를 출력한다.

## XM6 확인 범위

공식 기능을 다음 묶음으로 관리한다.

- 기기: 배터리, 충전, 펌웨어, 코덱, 연결 모드
- 소리: ANC/주변음, 주변음 단계, 음성 집중, EQ, Clear Bass, DSEE Extreme
- 자동 동작: 착용 감지, 자동 일시정지, 자동 전원 끄기, Speak-to-Chat
- 조작: 터치 패널, 버튼 전환 패턴, 음성 안내
- 연결: 멀티포인트, LE Audio 상태
- 앱 서비스 의존: Adaptive Sound Control, Quick Access, 서비스 연결, Auto Play,
  360/공간 음향은 기기 단독 명령인지 확인하기 전까지 미확인으로 둔다.

## 오류와 관찰 기록

사용자 오류, 연결 오류, 응답 없음, 지원하지 않는 기능을 구분한다. CLI에는 한국어
요약을 보여주고 `--json`에는 기계 판독 가능한 오류 코드를 넣는다. 실측 기록에는
시간, 방향, 명령 키, 데이터 종류, payload만 저장하며 개인 식별 가능한 MAC 주소는
fixture에 넣지 않는다.

## 테스트와 주석

프로토콜 데이터 묶음과 스트림 테스트는 하나의 파일로, CLI 명령 테스트는 하나의
파일로 통합한다. 단순히 파일 수만 줄이지 않고 파라미터화를 사용해 기존 경계 조건을
유지한다. 메시지 코덱과 기기 API는 가짜 세션으로 전량 단위 테스트하며, 실제 기기
테스트는 `hardware` 표식으로 분리한다.

한국어 주석은 바이트 위치, ACK 순서, 후보 응답 분리, 자동 복원처럼 코드만 보고
이유를 알기 어려운 불변 조건 위주로 추가한다. 이름으로 자명한 동작에는 주석을 달지
않는다.

## 법적·프로젝트 경계

사용자 소유 기기와 직접 통신한 블랙박스 관찰만 프로젝트의 근거로 삼는다. Sony 앱,
펌웨어, 바이너리를 역컴파일하거나 복제하지 않고 DRM·인증·보호 장치를 우회하지
않는다. 공개 서드파티 프로젝트는 기능 후보를 찾는 참고 자료일 뿐 코드를 복사하지
않으며 XM6에서 독립 검증한다. 프로젝트는 Sony와 무관한 비공식 도구임을 README에
명시한다.
