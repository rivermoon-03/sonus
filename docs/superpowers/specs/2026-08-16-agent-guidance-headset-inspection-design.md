# 에이전트 지침 최신화와 XM6 읽기 전용 조사 설계

## 목표

- 저장소 루트의 `AGENTS.md`가 `CLAUDE.md`를 가리키게 해 에이전트별 지침 중복을 없앤다.
- `CLAUDE.md`를 현재 구현된 Sonus 기능과 검증 절차에 맞게 최신화한다.
- 연결된 WH-1000XM6에서 안전하게 읽을 수 있는 현재 상태와 설정을 조사하고, 추가로 지원할 만한 기능을 정리한다.

## 변경 설계

`AGENTS.md`는 `CLAUDE.md`를 대상으로 하는 상대 심볼릭 링크로 만든다. 링크는 저장소를 다른 경로에 복제해도 유효해야 한다.

`CLAUDE.md`는 기존 계층·프로토콜·GUI 원칙을 유지하되 다음 내용을 보강한다.

- 현재 구현 상태: GUI는 아직 없고 Python 드라이버와 CLI가 구현되어 있음
- 주요 CLI: `probe`, `status`, `settings`, `discover`, `get`, `set`, 저수준 `sniff`와 `send`
- 현재 쓰기 허용 범위: 실기기에서 원상 복원까지 검증한 DSEE만 허용
- 검증 명령: 기본 단위 테스트와 명시적인 하드웨어 테스트
- 실기기 조사 규칙: 읽기 전용 명령을 우선하고 미확인 raw 명령이나 위험 기능은 실행하지 않음
- 실측 자료와 프로토콜 문서의 기록 위치

README나 프로토콜 문서에 이미 있는 상세 기능표와 법적 설명은 중복하지 않고 링크로 안내한다.

## 헤드셋 조사

현재 연결 정보는 `bluetoothctl info`로 확인한다. Sonus에서는 상태를 변경하지 않는 `status`, `settings`, `discover`를 실행해 현재 모델, 펌웨어, 배터리, 코덱, 오디오·착용·안전 관련 상태와 광고된 기능을 수집한다.

읽기 실패는 장치 또는 기능 단위로 기록하고, 연결 자체가 끊긴 경우에만 재연결 여부를 확인한다. `set`, raw `send`, 장시간 `sniff`, 전원·초기화·페어링·펌웨어 관련 동작은 이번 조사에서 실행하지 않는다.

## 검증

- `readlink AGENTS.md`와 링크 대상 파일 비교로 심볼릭 링크를 확인한다.
- `CLAUDE.md`의 명령과 실제 `sonus --help`가 일치하는지 확인한다.
- 전체 단위 테스트를 실행한다.
- 헤드셋 조회 결과는 사용자에게 현재 값, 조회 가능 범위, 미지원/미확인 범위, 안전한 다음 구현 후보로 구분해 전달한다.
