# XM6 공식 제품 이미지 적용 설계

## 목표

디자인 시스템 시안의 CSS 추상 헤드셋 도형을 Sony 공식 WH-1000XM6 블랙 제품 이미지로 교체한다.

## 자산과 출처

Sony 공식 제품 페이지에 사용된 정면 제품 PNG를 저장소의 `design-preview/assets/wh-1000xm6-black.png`에 보관한다. 원본 출처는 Sony 공식 WH-1000XM6 제품 페이지이며, 화면에는 작은 출처 표기와 공식 페이지 링크를 둔다. 외부 CDN 핫링크는 사용하지 않는다.

## 표현

이미지는 기존 제품 상태 패널의 왼쪽 영역에 `object-fit: contain`으로 배치한다. 라이트·다크 양쪽에서 자연스럽게 보이도록 배경은 투명 또는 중립 표면을 유지하고, 제품 전체가 잘리지 않게 한다. 기존 상태 정보와 반응형 레이아웃은 변경하지 않는다.

## 검증

- 다운로드 파일이 유효한 PNG이며 충분한 해상도를 가진다.
- HTML 대체 텍스트가 모델명과 색상을 설명한다.
- 1440px과 390px 렌더링에서 이미지가 잘리거나 상태 패널을 침범하지 않는다.
- 기존 Node와 Python 테스트가 모두 통과한다.
