# Sonus PyQt6 읽기 전용 GUI 설계

## 목표

승인된 절제 패널형 HTML/CSS/JS 시안을 실제 Linux 데스크톱 프로그램으로 구현한다. 앱은 연결된 WH-1000XM6의 상태와 알려진 설정을 읽어 표시하며, 첫 릴리스에서는 DSEE를 포함한 모든 설정 쓰기를 GUI에서 차단한다.

## 기술 선택

앱 셸은 PyQt6, 화면은 Qt WebEngine, Python과 JavaScript 연결은 Qt WebChannel을 사용한다. 이 조합은 현재 시안의 HTML/CSS/JS를 가장 정확하게 재사용하면서 시스템 트레이와 데스크톱 창 수명주기를 네이티브 Qt로 관리한다.

런타임 의존성에 `PyQt6`와 `PyQt6-WebEngine`을 추가하고 `sonus-gui` 콘솔 진입점을 제공한다. 웹 자산은 `src/sonus/gui/web/`에 패키지 데이터로 포함해 설치된 wheel에서도 네트워크 없이 로드한다. Pretendard는 오픈 라이선스 웹폰트 파일을 패키지에 포함하거나, 포함이 불가능한 경우 시스템 Pretendard와 산세리프 폴백을 사용한다. 제품 이미지는 기존 공식 Sony 로컬 자산을 사용한다.

## 구성 요소

### 앱 셸

`QApplication`, `QMainWindow`, `QWebEngineView`, `QWebChannel`, `QSystemTrayIcon`을 구성한다. 창은 최소 1120×720, 기본 1360×860으로 열리며 마지막 크기·위치와 테마를 `QSettings`에 저장한다. 트레이 메뉴는 창 열기, 새로고침, 종료를 제공하고 창 닫기는 종료가 아니라 트레이 숨김으로 처리한다. 트레이를 사용할 수 없는 환경에서는 일반 종료로 동작한다.

### 장치 연결 서비스

GUI는 `device` 공개 API만 사용한다. RFCOMM 채널 탐색, 연결, `ProtocolSession`, `SonyXm6Device` 조립을 GUI 밖의 공개 연결 팩토리로 이동해 CLI와 GUI가 공유한다. 첫 실행에는 현재 테스트 장치 주소를 기본 후보로 보여주되 사용자가 수정할 수 있으며, 주소와 선택 채널은 `QSettings`에 저장한다.

### 읽기 전용 작업자

Bluetooth I/O는 Qt 메인 스레드에서 실행하지 않는다. 전용 `QThread` 작업자가 연결을 열고 항목별로 `SonyXm6Device.get()`을 호출해 결과를 점진적으로 전달한다. 모델, 펌웨어, 배터리, 코덱, 연결 모드, 노이즈 제어, EQ, DSEE, 자동 일시정지, 자동 전원 끄기, Speak-to-Chat, 음성 안내와 음량, 착용 상태, 안전 청취·안전 음량을 조회한다.

현재 Classic RFCOMM에서 응답이 없는 LE Audio 상태·호환 전환과 탐색 전용 항목은 초기 새로고침에서 제외하고 화면에 `현재 연결에서 미확인`으로 표시한다. 새로고침 중복 실행은 무시하고, 창 종료 시 작업자 종료를 기다린다. GUI 코드에는 `set()` 호출 경로를 만들지 않는다.

### WebChannel 브리지

JavaScript에는 원시 프레임, 소켓, Python 예외를 전달하지 않는다. 브리지는 다음 이벤트와 슬롯만 공개한다.

- 초기 설정 요청: 저장된 기기 주소, 채널, 테마
- 연결/새로고침 요청
- 연결 상태 이벤트: 연결 중, 연결됨, 연결 실패, 연결 해제
- 항목 결과 이벤트: key, label, value, supported, writable=false, error
- 전체 새로고침 완료 이벤트
- 테마 저장 요청

오류는 `헤드셋을 찾지 못했습니다`, `Bluetooth 연결에 실패했습니다`, `기기 응답이 없습니다` 같은 사용자 문구로 변환한다. 항목 하나의 실패가 다른 항목 표시를 막지 않는다.

## 실제 화면

현재 디자인 시스템의 색·타이포·간격·표면·테마 토큰을 유지하되 내비게이션을 실제 앱 구조로 바꾼다.

- 상태: 공식 XM6 이미지, 연결 상태, 배터리, 코덱, 펌웨어, 연결 모드, 마지막 동기화
- 사운드: 노이즈 제어, 주변음 단계, DSEE, Speak-to-Chat, 음성 안내
- 이퀄라이저: 현재 프리셋과 10밴드 값을 읽기 전용 그래프로 표시
- 기기 설정: 착용 감지, 자동 전원 끄기, 안전 청취, 안전 음량, 착용 상태
- 정보: 앱 버전, 프로토콜 상태, 읽기 전용 정책, Sony 비제휴 고지

모든 토글, 선택, 슬라이더와 EQ 밴드는 실제 값을 표현하지만 비활성화하고 잠금 아이콘과 `읽기 전용` 배지를 표시한다. 값이 아직 없으면 스켈레톤 또는 대시를, 실패하면 항목 안에 `응답 없음`을 표시한다.

첫 화면에는 연결 설정 패널을 겹쳐 보여준다. MAC 주소와 선택 채널을 입력해 연결할 수 있고, 이후 상단의 기기 메뉴에서 변경할 수 있다. 라이트가 기본이며 다크 선택은 앱 재시작 후에도 유지된다.

## 패키징과 실행

- 개발 실행: `uv run sonus-gui`
- 선택적 장치 지정: `uv run sonus-gui --mac <MAC> --channel 9`
- 헤드리스 테스트에서는 `QT_QPA_PLATFORM=offscreen`, `QTWEBENGINE_DISABLE_SANDBOX=1`을 사용한다.

PyQt6가 없는 최소 드라이버 설치를 유지하지 않고 GUI 의존성을 기본 런타임에 포함한다. 이 프로젝트의 제품 목표가 데스크톱 앱이므로 설치 후 `sonus`와 `sonus-gui`가 모두 즉시 실행 가능해야 한다.

## 테스트

- 순수 상태 변환: `FeatureResult`가 화면 JSON으로 정확히 변환되는지 검사
- 연결 팩토리: 채널 자동 탐색, 명시 채널, 연결 종료를 가짜 전송 계층으로 검사
- 작업자: 점진 결과, 항목 실패 격리, 중복 새로고침 차단을 가짜 장치로 검사
- 브리지: 초기 설정, 테마 저장, 연결 요청과 사용자 오류 문구를 검사
- Qt 오프스크린: 메인 창 생성, 로컬 HTML 로드, WebChannel 등록, 트레이 없는 환경의 종료 동작 검사
- 웹 동작: 기존 Node 테마 테스트와 자산 테스트 유지
- 전체 Python 단위 테스트와 패키지 wheel 포함 파일 검사
- 실기기: 연결된 XM6에서 GUI 기본 읽기 목록을 검증하고, 별도로 `settings`와
  `discover`의 안전한 읽기 전용 항목을 모두 실행해 CLI 결과와 대조한다. 응답 없는
  항목의 타임아웃도 정상적인 부분 실패로 기록하되 쓰기 명령은 실행하지 않는다.

## 완료 조건

`sonus-gui`가 설치 환경에서 실행되고, 첫 연결 화면을 통해 XM6에 연결하며, 상태와 설정을 점진적으로 표시하고, 라이트/다크 테마와 시스템 트레이가 동작해야 한다. 모든 조작 컨트롤은 읽기 전용이어야 하며 네트워크 없이 로컬 UI 자산을 로드해야 한다. 자동화 테스트와 연결된 실기기 읽기 검증이 통과해야 한다.
