# Sonus GUI 디자인 시스템 시안 설계

## 목표

PyQt6 GUI 구현 전에 브라우저에서 빠르게 검토할 수 있는 독립 HTML/CSS/JS 디자인 시스템 페이지를 만든다. 시각 방향은 절제된 패널형이며 기본 테마는 라이트, 선택 가능한 보조 테마는 다크다.

## 범위와 구조

시안은 `design-preview/`에 두며 빌드 도구나 외부 JavaScript 의존성 없이 `index.html`, `styles.css`, `app.js`로 구성한다. 1440px 데스크톱 앱을 우선하되 좁은 화면에서도 내용이 잘리지 않도록 반응형으로 만든다.

왼쪽 고정 내비게이션에는 Foundations, Typography, Colors, Spacing, Components 항목을 두고, 오른쪽 콘텐츠 패널에는 다음 내용을 실제 토큰과 컴포넌트 예시로 보여준다.

- Pretendard 기반 표시·제목·본문·보조문 타이포 스케일과 자간
- 블루 포인트와 차가운 중성색 기반 라이트·다크 색상 토큰
- 4px 기반 간격, 반경, 테두리, 그림자 원칙
- 기본·보조·위험 버튼, 입력, 선택, 토글, 슬라이더, 상태 배지
- 헤드셋 상태를 암시하는 배터리·연결·ANC 예시 패널

## 디자인 원칙

- 기본 테마는 라이트이며 포인트 컬러는 `#2563EB` 계열 하나만 사용한다.
- 표면은 저채도 중성색, 얇은 테두리, 제한적인 그림자로 구분한다.
- 장식적 그라디언트와 과한 둥근 카드, 화려한 애니메이션은 사용하지 않는다.
- Pretendard를 우선 사용하고 로드 실패 시 시스템 산세리프 폴백을 쓴다.
- 본문은 읽기 편한 자간을 유지하고, 작은 라벨만 제한적으로 자간을 넓힌다.
- 포커스 표시, 대비, 폼 레이블을 포함해 키보드 접근성을 유지한다.

## 상호작용

헤더의 테마 토글은 라이트와 다크를 즉시 전환하고 선택을 `localStorage`에 저장한다. 최초 저장값이 없으면 시스템 설정과 무관하게 라이트를 사용한다. 내비게이션 항목은 대응 섹션으로 스크롤하고 현재 섹션을 표시한다.

시안의 입력·토글·슬라이더는 디자인 확인용으로 조작 가능하지만 실제 헤드셋이나 Sonus Python API에는 연결하지 않는다.

## 검증

- HTML, CSS, JavaScript가 별도 빌드 없이 브라우저에서 열린다.
- 최초 로드가 라이트 테마이며 전환 후 새로고침해도 선택이 유지된다.
- 1440px과 모바일 폭에서 콘텐츠가 겹치거나 잘리지 않는다.
- 모든 주요 토큰과 컴포넌트 상태가 한 페이지에서 비교 가능하다.
- 기존 Python 단위 테스트에 영향을 주지 않는다.
